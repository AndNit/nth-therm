# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

**NTH Therm GmbH** website — a bilingual (DE/EN) Hugo static site. DE is served at the root (`/`); EN is served under `/en/`. Deployed on Netlify.

Stack: Hugo Extended · Tailwind CSS v3 + PostCSS · Decap CMS (Git Gateway) · Formspree · Netlify.

## Commands

All commands run from within `nth-therm/`:

```bash
# Install CSS pipeline dependencies (required once, and after any package changes)
npm install

# Local dev server with live reload
hugo server -D

# Production build (output → ./public/)
hugo --minify
```

Hugo **Extended ≥ 0.120.0** is required. Netlify pins `HUGO_VERSION = "0.126.0"` and runs `npm ci && hugo --minify`.

## CSS Pipeline

`assets/css/main.css` is processed by Hugo via PostCSS (`css.PostCSS` in `baseof.html`), which runs Tailwind CSS v3 and Autoprefixer. Tailwind scans for class names using `hugo_stats.json` (generated by `[build] writeStats = true` in `hugo.toml`) rather than directly scanning templates — so `hugo_stats.json` must be up-to-date for new classes to appear in production builds. Preflight reset is disabled (`corePlugins.preflight: false`) since the site has its own reset.

A second static file, `static/css/animations.css`, is served as-is (not processed by PostCSS).

Design tokens live as CSS custom properties at the top of `main.css` (palette, fonts, spacing scale).

## Architecture

### Multilingual Content

Content is split into `content/de/` and `content/en/`. DE is the primary language and is served at the **root** (no `/de/` prefix). EN is served under `/en/` with English slugs (e.g. `industrieoefen/` → `industrial-furnaces/`). Pages are paired across languages via a shared `translationKey` in front matter.

`netlify.toml` redirects `/` → `/en/` for EN-language browsers (302), and redirects any legacy `/de/*` paths → root DE URLs (301).

### Layout System

`layout` in front matter controls which Hugo template is used. Hugo checks `layouts/<layout>/single.html` first, then falls back to `layouts/_default/<layout>.html`.

| `layout` value | Used for |
|---|---|
| `home` | Homepage (`_index.md`) — uses `layouts/home/list.html` |
| `product` | Product pages |
| `service` | Service pages |
| `contact` | Contact page |
| `about` | About / Über uns page |
| `project-form` | Furnace configurator |
| `legal` | Imprint / Privacy |
| `application` | Application pages (anlassen, gluehen, …) |
| `industry` | Industry pages (automotive, branchen, …) |
| `section-furnaces` | Section index for industrial furnaces |
| `landingpage` | Landing pages |

`layouts/_default/baseof.html` is the HTML shell: SEO meta, hreflang, Open Graph, cookie banner, PostCSS stylesheet, and `static/js/main.js`.

Section indexes without a `layout` field fall through to `layouts/_default/list.html`.

### Navigation

The navigation in `layouts/partials/header.html` is **hardcoded** — all nav items and dropdown links are written directly in the template with `{{ if eq $lang "de" }}…{{ else }}…{{ end }}` branches. The `[menu.main]` entries in `hugo.toml` are **not** used by the header partial. When adding, renaming, or reordering nav items, edit `header.html` directly.

### Schema / Structured Data

`partials/schema.html` emits JSON-LD based on page context:
- **Organization** — always
- **BreadcrumbList** — every non-home page
- **Product** — when `layout: product` (uses `specs.temp_range` for `additionalProperty`)
- **FAQPage** — when `faqs` front matter array is present
- **HowTo** — on the home page when `steps` is present

### Front Matter Conventions

Product pages (`layout: product`):
```yaml
translationKey: "chamber-furnace-icf"
layout: "product"
description: "…"          # used for meta and Product schema
specs:
  temp_range: "50–1300 °C"
  uniformity: "…"
  atmosphere: "…"
  loading: "…"
  control: "…"
  vacuum: "…"
applications:
  - "Application 1"
faqs:
  - q: "Question"
    a: "Answer"
cta:
  headline: "…"
  text: "…"
  button: "…"
  url: "/kontakt/?produkt=kammerofen-icf"
```

Homepage (`_index.md`) uses `hero`, `usps`, `steps`, `products_teaser`, `faqs`, and `partners` keys.

### Internationalisation

UI strings are in `i18n/de.toml` and `i18n/en.toml`. Access via `{{ i18n "key" }}` in templates.

### CMS

`static/admin/` — Decap CMS with Git Gateway backend. Protected by Netlify Identity at `/admin/`. The `noindex` header is set in `netlify.toml`.

### Forms

Contact forms POST to Formspree. Endpoint configured in `hugo.toml`:
```toml
formspreeEndpoint = "https://formspree.io/f/YOUR_FORM_ID"
```
